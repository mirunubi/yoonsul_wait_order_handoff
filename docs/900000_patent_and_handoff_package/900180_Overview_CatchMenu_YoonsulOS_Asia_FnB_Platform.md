## 3. 문제 정의

```text
F&B 매장의 3대 고질 문제:

문제 1: 운영 비효율
  주문 → 조리 → 서빙 파이프라인 단절
  대기 시간이 낭비 시간
  POS/KDS/DID 가 각각 따로 작동
  실시간 데이터 없음

문제 2: 인력 불안정
  F&B 구인이 가장 어려운 업종
  검증된 인력 수급 채널 없음
  인력 수요 예측 불가
  좋은 직원 = 운에 의존

문제 3: 위생/법규 부담
  HACCP 준수 비용 과다
  수동 체크리스트 비효율
  식중독 사고 = 브랜드 소멸
  중소 매장 대응 능력 없음

이 3가지를 동시에 해결하는
플랫폼이 한국에 없다
```

## 4. 솔루션

```text
캐치메뉴 (고객 접점 OS):
  대기 → 사전 주문 → 착석
  → 결제 → KDS 활성화 → 서빙
  이 파이프라인을 디지털로 완성

  핵심 특허:
  Patent 2: 결제 확인 → KDS 활성화
  "대기 시간을 주문 준비 시간으로"

윤슬OS (운영 백오피스):
  재고/원가/정산 자동화
  CCP 미니버전 (HACCP 경량화)
  AI SOP 자가진화
  멀티브랜드 통합 관리

윤슬 Workforce (인력 플랫폼):
  F&B 특화 인력 매칭
  운영 데이터 기반 수요 예측
  당근/알바천국 제휴
  직업소개소 자격증 기반

윤슬 브랜드 (자체 검증):
  윤슬김밥 → 보울 → 야식 → 음료
  플랫폼을 직접 사용하며 고도화
  "우리가 첫 번째 고객"
```
