## 0. Document Purpose

이 Policy 문서는 윤슬OS 의 멀티 브랜드 확장 전략과
AI 접목 범용 F&B 운영 OS SaaS 비전을 정의한다.

```text
윤슬OS 최종 비전:
  한국형 치폴레/서브웨이 모델
  + 멀티 브랜드 F&B 그룹
  + AI 접목 범용 F&B SaaS

핵심 개념:
  OS 가 브랜드를 만드는 게 아니라
  OS 위에 브랜드가 올라타는 구조

  윤슬OS = F&B 용 운영 인프라
  각 브랜드 = 그 위에 올라가는 서비스
```

---

## 1. 브랜드 확장 로드맵

```text
1단계: 윤슬김밥 (현재)
  서울 1호점 오픈
  캐치메뉴 임베디드 검증
  운영OS 기반 구축

2단계: 윤슬보울
  보울 전문 브랜드
  (한식/아시안 보울 베이스)
  윤슬OS 위에 올라탐
  메뉴 구성만 다름
  운영 파이프라인 동일

3단계: 야식 브랜드
  야간 특화 (오후 9시~새벽 2시)
  배달 중심
  피크타임 예측 AI 활용
  심야 재고 관리 자동화

4단계: 음료 브랜드
  음료 전문
  빠른 회전율 특화
  키오스크 중심 운영
  대기 시간 최소화 AI

공통 인프라:
  모든 브랜드 = 윤슬OS + 캐치메뉴
  브랜드만 다르고 운영 파이프라인 동일
  본사 → 각 브랜드 운영 품질 통합 관리
```

## 2. 치폴레/서브웨이 모델 분석

```text
치폴레 강점:
  메뉴 표준화 (적은 SKU)
  재료 원가 투명 관리
  매장별 수익성 실시간 파악
  운영 매뉴얼 표준화

서브웨이 강점:
  커스터마이징 → 고객 참여
  프랜차이즈 확장 용이
  낮은 진입 비용

우리가 추가하는 것:
  AI 기반 운영 최적화
  실시간 KDS 연동 효율화
  대기 시간 → 주문 시간으로 전환
  데이터 기반 메뉴 개선
  크로스 브랜드 인사이트

한국형 차별점:
  김밥/보울/야식/음료 = 한국 외식 핵심
  배달앱 연동 최적화
  알레르겐 법적 준수 자동화
  외국인 다국어 대응
```

## 3. AI 접목 방향

### 3.1 브랜드별 AI 활용

```text
윤슬김밥:
  주문 패턴 분석 → 인기 메뉴 예측
  피크타임 재료 사전 준비
  알레르겐 자동 안내
  KDS 조리 시간 최적화

윤슬보울:
  재료 조합 추천 (벡터 유사도)
  영양 정보 자동 계산
  커스터마이징 최적 조합 제안
  재료 원가율 실시간 분석

야식 브랜드:
  야간 수요 예측 (날씨/이벤트 연동)
  배달 최적 시간 분석
  심야 재고 자동 발주
  배달앱 주문 우선순위 AI 분류

음료 브랜드:
  날씨/계절 수요 예측
  제조 시간 KDS 최적화
  인기 조합 자동 추천
  원가율 실시간 알림
```

### 3.2 크로스 브랜드 AI

```text
데이터 집계:
  모든 브랜드 운영 데이터 통합
  고객 행동 패턴 크로스 분석
  브랜드 간 상호 보완 발견

예시:
  음료 브랜드 방문 고객이
  야식 브랜드도 방문하는 패턴 발견
  → 크로스 쿠폰 발행

  김밥 브랜드 피크타임에
  보울 브랜드 대기 유도
  → 부하 분산

SaaS 활용:
  외부 F&B 에 AI 인사이트 판매
  업종별 벤치마크 데이터
  운영 최적화 컨설팅
```

### 3.3 AI SOP 자가진화 (Patent C 연동)

```text
브랜드별 반복 문제 자동 감지
→ SOP 후보 자동 생성
→ 승인 후 전 브랜드 배포

예시:
  야식 브랜드에서 심야 재료 부족
  반복 발생 감지
  → "심야 2시간 전 재고 체크" SOP 자동 생성
  → 전 야식 매장 자동 적용

  음료 브랜드에서 여름 특정 메뉴 품절
  반복 감지
  → "기온 30도 이상 시 해당 재료 2배 주문" SOP
  → AI 날씨 연동 자동 발주
```

## 4. 윤슬OS SaaS 화 전략

```text
1단계: 내부 검증 (지금~2027)
  윤슬김밥 서울 1호점
  캐치메뉴 임베디드 운영
  데이터 축적 + 문제 해결

2단계: 멀티 브랜드 검증 (2027~2028)
  윤슬보울 오픈
  야식 브랜드 오픈
  크로스 브랜드 운영 최적화

3단계: 외부 SaaS 출시 (2028~)
  검증된 운영OS 외부 판매
  프랜차이즈 패키지
  "캐치메뉴 + 윤슬OS 번들"

타겟 고객:
  소형 F&B 프랜차이즈 (5~20개 매장)
  신규 브랜드 창업자
  다점포 운영 확장 중인 매장

가격 모델:
  매장당 월 SaaS 구독
  온보딩 서비스
  AI 분석 리포트 구독
  교육/컨설팅 패키지
```

## 5. 캐치메뉴와 윤슬OS 역할 분리

```text
캐치메뉴 (고객 접점):
  대기 / 주문 / 결제 / KDS
  DID / 키오스크 / 고객앱
  쿠폰 플랫폼
  슬롯 컨테이너 Agent

윤슬OS (운영 백오피스):
  직원 인사 / 노무 / 급여
  식재료 발주 / 재고 관리
  원가 분석 / 수익성 관리
  가맹 계약 / 로열티 정산
  브랜드별 운영 품질 관리

연결 지점:
  캐치메뉴 매출 → 윤슬OS 수익 분석
  윤슬OS 재고 → 캐치메뉴 품절 이벤트
  윤슬OS 직원 → 캐치메뉴 직원앱
  (Phase 3 이후 API 연동)

분리 원칙:
  두 시스템은 현재 별개
  고객 앱은 캐치메뉴만 사용
  직원 앱은 캐치메뉴 직원앱 사용
  윤슬OS = 별도 백오피스
```
