## 0. Document Purpose

이 Policy 문서는 윤슬 Workforce 플랫폼 전략과
아시아 F&B 시장 확장 비전을 정의한다.

```text
단기 목표:
  직업소개소 개업 (프랜차이즈 진입 전)
  F&B 특화 인력 네트워크 구축
  캐치메뉴 개발 자금 확보

중기 목표:
  당근/알바천국 제휴
  윤슬 Workforce 플랫폼 런칭
  F&B 전체 플랫폼 완성

장기 목표:
  아시아 F&B 운영 인프라
  졸리비를 넘어서는
  OS 기반 멀티브랜드 F&B 그룹
```

---

## 1. 직업소개소 먼저 하는 이유

```text
1. 현금 흐름 확보
   프랜차이즈 개발 기간 동안
   직업소개소 수익으로 운영 자금 충당
   캐치메뉴/윤슬OS 개발 비용 확보

2. F&B 인력 네트워크 선점
   좋은 주방장/직원 미리 확보
   윤슬김밥 1호점 오픈 시
   검증된 인력 즉시 투입 가능

3. 시장 데이터 수집
   F&B 매장들의 인력 니즈 파악
   어떤 포지션 수요가 많은지
   향후 Workforce 플랫폼 설계 기초

4. 법적 기반 확보
   직업소개소 자격증 = 합법적 인력 소개
   당근/알바천국 제휴 시 법적 근거

5. 영업 채널
   직업소개소 고객사 → 캐치메뉴 영업
   인력 소개 + 운영OS 번들 제안
```

---

## 2. 직업소개소 사업 구조

```text
사업명: F&B 특화 직업소개소

특화 포지션:
  주방장 (파트/풀타임)
  카운터/서빙 직원
  배달 전담 직원
  키오스크 운영 직원
  매장 관리자

수익 모델:
  구인 성공 건당 수수료
    (월급의 1개월치 또는 정액)
  단기 파견 마진
    (시급 기반)
  교육 프로그램 수료비
    (F&B 특화 교육)

차별화:
  캐치메뉴 KDS 조작 교육 포함
  매장 운영OS 기본 교육
  "캐치메뉴 인증 직원" 등급제
  → 인증 직원 = 우선 매칭 + 높은 시급
```

## 3. 캐치메뉴 + 직업소개소 시너지

```text
직업소개소 → 캐치메뉴:
  고객 매장에 캐치메뉴 SaaS 영업
  "인력 소개해드리고 운영OS 도 써보세요"
  번들 할인 제공

캐치메뉴 → 직업소개소:
  도입 매장에서 인력 수요 발생 시
  직업소개소로 즉시 연결
  KDS 데이터 → 인력 필요 시점 예측

운영 데이터 활용:
  매장 피크타임 분석
  → 정확한 인력 투입 시간 계산
  → 파트타임 매칭 최적화

  KDS 병목 감지
  → 주방 인력 추가 요청
  → 즉시 대응 인력 풀 운영
```

## 4. Workforce 플랫폼 로드맵

```text
Phase 1 (지금): 직업소개소
  오프라인 F&B 특화 인력 소개
  수동 매칭
  네트워크 구축

Phase 2 (2027): 디지털 플랫폼
  앱/웹 기반 매칭 플랫폼
  캐치메뉴 연동
  매장 수요 예측 자동화

Phase 3 (2028): 당근/알바천국 제휴
  제휴 방식 A: 인력 공급
    → 일반 구직자를 F&B 특화로 전환
  제휴 방식 B: 데이터 연동
    → 윤슬OS 수요 예측 → 자동 공고
  제휴 방식 C: 공동 상품
    → "F&B 전문 알바" 카테고리 공동 운영

Phase 4 (2029+): AI 인력 최적화
  운영 데이터 기반 인력 수요 예측
  최적 인력 자동 매칭
  성과 기반 평가 시스템
```

## 5. 아시아 F&B 확장 비전

### 5.1 졸리비 모델 분석

```text
졸리비 강점:
  필리핀 기반 아시아 최대 F&B 그룹
  자체 브랜드 다수 보유
  동남아/미국 확장 완료

졸리비 한계:
  브랜드 중심 (OS 없음)
  각국 별도 운영 (비효율)
  IT 시스템 분산
  AI 운영 최적화 없음
  인력 플랫폼 없음

우리 차별점:
  OS 가 먼저 → 브랜드가 올라탐
  단일 OS 위에 각국 브랜드
  AI 현지화 자동화
  Workforce 통합
  감사 원장 기반 투명 운영
```

---

### 5.2 아시아 진출 순서

```text
1단계: 한국 완성 (2026~2028)
  윤슬김밥 → 보울 → 야식 → 음료
  캐치메뉴 SaaS 국내 검증
  Workforce 플랫폼 완성
  F&B 전체 플랫폼 완성

2단계: 동남아 1차 (2028~2030)
  베트남 우선:
    한식 인기 + 젊은 인구
    F&B 시장 빠른 성장
    캐치메뉴 베트남어 이미 준비 (vi) ✓
  태국:
    관광객 + F&B 고성장
    한류 영향력
    캐치메뉴 태국어 준비 필요

3단계: 동남아 2차 (2030~2032)
  인도네시아:
    2억 7천만 인구
    최대 동남아 시장
  필리핀:
    졸리비 홈그라운드 진입
    한식 인기 높음
  말레이시아:
    다문화 시장
    할랄 메뉴 대응 필요

4단계: 동북아 (2032~)
  일본:
    프리미엄 한식 포지셔닝
    고객 서비스 기준 높음
    캐치메뉴 일본어 이미 준비 (ja) ✓
  중국:
    파트너십 방식
    현지 플랫폼 연동 필요
```

---

### 5.3 현지화 전략

```text
메뉴 현지화:
  한국 김밥 → 현지 재료 버전
  한국 보울 → 현지 소스/재료 조합
  AI 가 현지 선호도 분석
  → 최적 메뉴 조합 자동 추천

운영 현지화:
  현지 POS 연동 (국가별 POS Gateway)
  현지 결제 수단 연동
    베트남: VNPay/Momo
    태국: PromptPay
    인도네시아: GoPay/OVO
  현지 배달앱 연동
    베트남: ShopeeFood/GrabFood
    태국: GrabFood/Foodpanda

인력 현지화:
  윤슬 Workforce → 현지 파트너 제휴
  현지 인력 플랫폼 연동
  F&B 특화 교육 현지어로 제공

OS 현지화:
  캐치메뉴 다국어 이미 준비
    ko/en/zh/ja/vi/th ✓
  현지 세금/영수증 규정 대응
  현지 식품위생법 알레르겐 대응
```

---

### 5.4 졸리비를 넘어서는 구조

```text
졸리비 모델:
  음식 회사 → 브랜드 확장
  각국 별도 운영
  IT 분산

우리 모델:
  OS 회사 → 브랜드 올라탐
  단일 OS 글로벌 운영
  AI 중앙화

구체적 차이:

  졸리비: 새 국가 진출 = 운영 처음부터
  우리:   새 국가 진출 = OS 이미 있음
          메뉴/결제/인력만 현지화

  졸리비: 인력 관리 = 국가별 별도
  우리:   Workforce 플랫폼 = 전체 통합
          AI 인력 최적화

  졸리비: 쿠폰 = 단순 발행
  우리:   쿠폰 = AI 개인화 + 운영 데이터 연동

이것이 아시아 F&B 의 빈 자리
```

## 6. 전체 플랫폼 완성도

```text
F&B 전체 플랫폼 구성:

[캐치메뉴] 고객 접점
  대기/주문/결제/KDS/DID
  쿠폰 플랫폼
  SaaS 외부 판매

[윤슬OS] 운영 백오피스
  멀티브랜드 운영
  재고/원가/정산
  AI 운영 최적화

[윤슬 Workforce] 인력 플랫폼
  F&B 특화 인력 소개
  AI 수요 예측 매칭
  당근/알바천국 제휴

[윤슬 브랜드] 자체 브랜드
  김밥/보울/야식/음료
  아시아 현지화 확장

이 4개가 합쳐지면:
  고객 + 운영 + 인력 + 브랜드
  = F&B 산업 전체 인프라
  = 아시아에서 누구도 못 따라오는 구조
```
