## 2. Revision Note

기존 SOP는 일반 들기름막국수 계열로 작성되었으나, 본 수정본은 원조 레시피로 지칭된 `꼬소한 불마요 들기름 막국수` 기준으로 재작성한다.

핵심 차이:

| 기존 일반형 | 수정 원조형 |
|---|---|
| 맛간장 + 쯔유 + 설탕 + 들기름 | 들기름 + 참소스 + 불닭소스 + 불닭마요 + 계란 노른자 |
| 김가루/감태 중심 | 김자반 + 갈아 올린 볶음참깨 |
| 담백한 들기름막국수 | 매콤·고소·마요·노른자 유화형 |
| 선택 계란 | 노른자 1알이 소스 구성 핵심 |

## 3. Purpose

본 SOP는 정국 원조형 `꼬소한 불마요 들기름 막국수`를 매장 또는 테스트 키친에서 일정한 품질로 조리·제공하기 위한 표준 절차를 정의한다.

핵심 목표는 다음과 같다.

```text
저온압착 생들기름의 고소함
불닭소스의 매콤함
불닭마요의 부드러움
참소스의 새콤짭짤한 감칠맛
계란 노른자의 유화감
김자반과 갈아 올린 볶음참깨의 마감
```

---

## 4. Menu Concept

정국 원조형 꼬소한 불마요 들기름 막국수는 차갑게 헹군 메밀면에 들기름·참소스·불닭소스·불닭마요·계란 노른자로 만든 소스를 버무리고, 김자반과 갈아 올린 볶음참깨를 올려 제공하는 매콤고소한 냉비빔면 메뉴다.

맛의 방향은 다음과 같다.

| 요소 | 목표 |
|---|---|
| 향 | 들기름의 고소한 향이 가장 먼저 올라와야 한다 |
| 매운맛 | 불닭소스가 중심을 잡되, 불닭마요와 노른자가 둥글게 잡아준다 |
| 산미/간 | 참소스의 새콤짭짤한 감칠맛 |
| 질감 | 노른자와 마요가 소스를 부드럽게 유화 |
| 면 | 찬물에 충분히 헹궈 전분기를 제거하고 물기를 최대한 제거 |
| 마감 | 김자반과 갈아 올린 볶음참깨가 고소함을 강화 |

## 5. Standard Serving Size

원조 레시피는 “메밀면 먹고 싶은 만큼”을 기준으로 하나, 매장 SOP에서는 1인분을 표준화한다.

| Item | 1인분 기준 |
|---|---:|
| 메밀면 건면 | 100~120 g |
| 저온압착 생들기름 100% | 4 Tbsp |
| 참소스 | 2 Tbsp |
| 불닭소스 | 1 Tbsp |
| 불닭마요소스 | 1 Tbsp |
| 계란 노른자 | 1알 |
| 김자반 | 8~15 g |
| 볶음참깨 | 1~2 Tbsp |
| 선택: 다진 양파 | 최대 1/4개 |
| 선택: 고춧가루 | 최대 1 Tbsp |
| 선택: 다진 마늘 | 최대 1/4 Tbsp |
| 얼음물 | 면 헹굼용 충분량 |

## 6. Core Sauce Ratio

원조형 핵심 소스 비율:

```text
들기름 4
참소스 2
불닭소스 1
불닭마요 1
계란 노른자 1
```

### 6.1 1인분 소스

| Ingredient | Amount |
|---|---:|
| 저온압착 생들기름 100% | 4 Tbsp |
| 참소스 | 2 Tbsp |
| 불닭소스 | 1 Tbsp |
| 불닭마요소스 | 1 Tbsp |
| 계란 노른자 | 1알 |

### 6.2 선택 보강

| Ingredient | Amount | Use |
|---|---:|---|
| 다진 양파 | 1/4개 이하 | 단맛과 식감 |
| 고춧가루 | 1 Tbsp 이하 | 매운맛과 색감 |
| 다진 마늘 | 1/4 Tbsp 이하 | 알싸한 향 |

## 9. Preparation Before Service

### 9.1 Sauce Prep Rule

소스는 가능하면 주문 직전 제조한다.

계란 노른자가 들어가므로 대량 배치 후 장시간 보관은 권장하지 않는다.

### 9.2 Garnish Prep

1. 김자반은 밀폐 용기에 보관한다.
2. 볶음참깨는 제공 직전 갈거나, 피크타임 전 소량만 갈아둔다.
3. 계란은 냉장 보관하고 주문 직전 분리한다.
4. 노른자 사용 시 알끈/힘줄은 제거한다.

### 9.3 Noodle Prep

메밀면은 사전 삶아 보관하지 않는 것을 원칙으로 한다.  
면의 전분기 제거와 물기 제거가 맛을 좌우한다.

## 10. Cooking Procedure

### 10.1 소스 만들기

1. 믹싱볼에 들기름 4 Tbsp를 넣는다.
2. 참소스 2 Tbsp를 넣는다.
3. 불닭소스 1 Tbsp를 넣는다.
4. 불닭마요소스 1 Tbsp를 넣는다.
5. 계란 노른자 1알을 넣는다.
6. 노른자의 알끈/힘줄은 제거한다.
7. 소스가 균일하게 섞이도록 충분히 저어 유화한다.
8. 선택 보강형일 경우 다진 양파, 고춧가루, 다진 마늘을 정해진 양만 넣는다.

### 10.2 면 삶기

1. 냄비에 충분한 물을 끓인다.
2. 물이 완전히 끓으면 메밀면 100~120 g을 넣는다.
3. 초반 30초간 저어 면이 붙지 않게 한다.
4. 제품 권장 삶는 시간을 기준으로 삶되, 매장 표준 시간은 테스트 후 고정한다.
5. 면이 익으면 즉시 채반에 건진다.

### 10.3 면 헹굼

1. 찬물로 1차 헹궈 전분기를 제거한다.
2. 얼음물 또는 아주 찬물로 2차 냉각한다.
3. 손으로 면을 비벼 전분기를 충분히 제거한다.
4. 채반에서 물기를 최대한 제거한다.
5. 물기가 많으면 소스가 희석되어 싱거워지므로 물기 제거를 강하게 관리한다.

### 10.4 버무림

1. 물기를 제거한 면을 소스 볼에 넣는다.
2. 면 전체에 소스가 균일하게 입도록 빠르게 버무린다.
3. 소스가 너무 묽으면 면 물기 제거가 부족한 것으로 본다.
4. 소스가 과하게 뻑뻑하면 면 양 또는 소스 계량을 재확인한다.

### 10.5 플레이팅

1. 버무린 면을 그릇 중앙에 담는다.
2. 김자반을 충분히 올린다.
3. 볶음참깨를 갈아서 위에 올린다.
4. 필요 시 소량의 추가 김자반을 가장자리에 더한다.
5. 즉시 제공한다.

## 12. Quality Control

### 12.1 Pass Criteria

- 들기름 향이 선명하다.
- 소스가 분리되지 않고 면에 잘 코팅된다.
- 면이 차갑고 전분기가 적다.
- 김자반이 눅눅하지 않다.
- 볶음참깨 향이 살아 있다.
- 매운맛, 마요의 부드러움, 노른자의 유화감이 균형을 이룬다.
- 물기 때문에 맛이 흐려지지 않는다.

### 12.2 Fail Criteria

| Failure | Cause | Corrective Action |
|---|---|---|
| 맛이 싱거움 | 면 물기 과다 | 면 물기 제거 강화 |
| 기름이 분리됨 | 소스 유화 부족 또는 면 물기 과다 | 노른자와 소스를 먼저 충분히 섞기 |
| 너무 매움 | 불닭소스 과다 | 1 Tbsp 고정, 고객 선택형 분리 |
| 너무 느끼함 | 들기름 과다 또는 면 양 부족 | 면 기준량/소스 계량 재확인 |
| 산패취 | 들기름 산패 | 즉시 폐기 |
| 비린맛 | 계란 신선도 또는 보관 문제 | 계란 폐기 및 신선란 사용 |
| 김자반 눅눅함 | 보관 습기 | 밀폐 보관, 눅눅한 제품 폐기 |
| 면이 떡짐 | 전분기 제거 부족 | 찬물에 충분히 비벼 헹굼 |
