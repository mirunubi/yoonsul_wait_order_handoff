## 5. 마늘쫑 기준

### 5.1 품질 기준

마늘쫑은 다음 기준을 만족해야 한다.

- 선명한 초록색
- 과도하게 질기지 않을 것
- 마른 끝부분이 심하지 않을 것
- 이취가 없을 것
- 물러짐이 없을 것
- 절단면 변색이 심하지 않을 것
- 씹었을 때 아삭함이 있을 것

질기거나 마른 마늘쫑은 사용하지 않는다.

### 5.2 전처리 기준

마늘쫑은 다음 절차로 전처리한다.

1. 마늘쫑 상태를 확인한다.
2. 마른 끝부분이나 질긴 부분을 제거한다.
3. 흐르는 물에 세척한다.
4. 물기를 충분히 제거한다.
5. 김밥 속재료에 맞는 크기로 자른다.
6. 필요 시 짧게 데치거나 볶아 매운맛과 질김을 조정한다.
7. 사용 전까지 냉장 보관한다.

### 5.3 절단 기준

마늘쫑은 김밥 절단면에서 식감이 살아야 하므로 너무 잘게 다지지 않는다.

초기 테스트 기준은 다음과 같다.

- 짧은 송송 절단형: 아삭함과 분산성 우수
- 2~3cm 절단형: 식감 강조, 조립 난이도 증가
- 잘게 다진 형: 향은 퍼지지만 존재감 약화

초기 표준은 송송 절단형으로 테스트한다.

## 6. 매운불고기 소스 기준

### 6.1 소스 방향

마늘쫑 매운불고기 소스는 고추장 베이스의 매콤달콤한 맛을 기준으로 한다.

소스의 목적은 다음과 같다.

- 반반 다짐육에 매운맛과 감칠맛 부여
- 마늘쫑의 알싸함과 조화
- 김밥 속재료로 사용할 수 있도록 수분을 과하게 남기지 않음
- 상시 간장 불고기 메뉴와 명확한 맛 차이 형성
- 봄철 시즌 메뉴로 기억될 수 있는 인상 부여

### 6.2 기본 소스 구성

초기 테스트용 소스 구성은 다음 방향으로 설계한다.

- 고추장
- 고춧가루
- 다진 마늘
- 간장 소량
- 매실청
- 설탕 또는 비정제당 소량
- 물엿 또는 조청 소량
- 후추
- 참기름
- 깨
- 양파즙 또는 양파 다짐 선택 가능

정확한 배합비는 테스트 조리 후 별도 레시피 카드에서 확정한다.

## 7. 조리 전 준비

조리 전 다음 사항을 확인한다.

- 반반 다짐육 원팩 라벨 확인
- 제조일 및 사용기한 확인
- 냉장 또는 해동 상태 확인
- 이취, 변색, 점액 여부 확인
- 마늘쫑 세척 및 절단 상태 확인
- 매운불고기 소스 준비 여부 확인
- 조리도구 세척 및 소독 확인
- 팬 또는 볶음솥 예열 상태 확인
- 완성 후 담을 트레이 준비

라벨이 없거나 사용기한이 불명확한 원팩은 사용하지 않는다.

## 8. 조리 절차

### 8.1 기본 볶음 절차

1. 팬 또는 볶음솥을 예열한다.
2. 필요 시 소량의 식용유를 두른다.
3. 반반 다짐육 원팩을 넣고 중강불에서 풀어가며 볶는다.
4. 고기가 뭉치지 않도록 주걱으로 고르게 풀어준다.
5. 고기 표면의 붉은 기가 사라질 때까지 1차 볶음한다.
6. 과도한 수분이나 기름이 많으면 일부 제거한다.
7. 고추장 베이스 매운불고기 소스를 넣는다.
8. 소스가 고기에 흡착되도록 계속 볶는다.
9. 국물이 남지 않도록 바싹 볶는다.
10. 마늘쫑을 투입한다.
11. 마늘쫑의 색과 아삭함이 유지되도록 짧게 볶거나 버무린다.
12. 마지막에 참기름과 깨를 넣어 마무리한다.
13. 완성된 볶음육을 트레이에 펼쳐 빠르게 식힌다.

### 8.2 마늘쫑 투입 방식

마늘쫑 투입 방식은 테스트를 통해 확정한다.

초기 후보는 다음과 같다.

- 볶음 마지막 투입형: 고기와 잘 섞이고 맛이 안정적
- 조립 직전 버무림형: 아삭함과 초록색 유지에 유리
- 김밥 조립 시 별도 배치형: 절단면 존재감이 좋지만 작업 난이도 증가

초기 표준은 볶음 마지막 투입형으로 테스트하되, 마늘쫑 식감이 죽으면 조립 직전 버무림형으로 전환한다.

## 9. 바싹 볶음 기준

본 메뉴도 김밥 속재료로 사용되므로 국물이 남지 않는 바싹 볶음을 기준으로 한다.

다음 상태를 목표로 한다.

- 팬 바닥에 소스가 흥건하게 남지 않음
- 고기에 고추장 소스가 고르게 코팅됨
- 마늘쫑 색이 과하게 죽지 않음
- 김밥에 넣었을 때 밥이 젖지 않음
- 매운맛이 과하게 튀지 않음
- 식어도 고기 풍미와 마늘쫑 향이 유지됨

## 10. 금지되는 조리 상태

다음 상태는 불량으로 본다.

- 국물이 많이 남은 상태
- 고기가 큰 덩어리로 뭉친 상태
- 고추장이 타서 쓴맛이 나는 상태
- 매운맛만 강하고 단맛과 감칠맛이 없는 상태
- 마늘쫑이 갈색으로 죽은 상태
- 마늘쫑이 질긴 상태
- 김밥 조립 시 밥을 젖게 만드는 상태

### 11.2 조립 원칙

마늘쫑 매운불고기 김밥은 매운불고기 풍미와 마늘쫑 식감이 동시에 느껴져야 한다.

조립 시 다음 기준을 따른다.

- 밥은 과도하게 두껍게 깔지 않는다.
- 매운불고기 볶음육은 중앙에 고르게 배치한다.
- 마늘쫑이 한쪽으로 몰리지 않도록 한다.
- 단무지와 절임채소는 매운맛 균형을 고려해 사용한다.
- 계란지단은 매운맛을 부드럽게 받쳐주는 역할로 사용한다.
- 깻잎은 향이 과하지 않은 범위에서 선택 적용한다.
- 김밥을 말 때 매운불고기 속재료가 빠지지 않도록 한다.

- 고추장 쓴맛이 나면 볶음 온도 또는 투입 시점을 조정한다.
- 고기 잡내가 있으면 마늘, 후추, 양파 처리를 조정한다.
- 마늘쫑이 질기면 절단 크기, 데침 여부, 투입 시점을 조정한다.
- 마늘쫑 향이 약하면 투입량 또는 투입 시점을 조정한다.
- 수분이 많으면 볶음 시간을 늘리거나 소스 투입량을 줄인다.
- 김밥 안에서 존재감이 약하면 매운불고기 또는 마늘쫑 투입량을 조정한다.

## 19. 알레르기 및 표시 검토

본 메뉴는 다음 표시 검토가 필요하다.

- 소고기
- 돼지고기
- 대두
- 밀
- 참깨
- 계란
- 고추장 및 소스 원료에 포함된 알레르기 유발 성분

정식 판매 전 원산지 표시, 알레르기 표시, 영양 정보 산정이 필요하다.

## 20. 금지 사항

다음 행위는 금지한다.

- 라벨 없는 반반 다짐육 원팩 사용
- 사용기한 불명확한 원육 사용
- 해동 후 재냉동 원육 사용
- 국물이 많은 상태의 매운불고기 볶음육 사용
- 탄맛 또는 쓴맛이 강한 볶음육 사용
- 질기거나 변색된 마늘쫑 사용
- 전날 잔량을 신규 볶음육과 임의 혼합
- 메뉴별 소스가 섞인 볶음육을 공통 원육으로 되돌림
- 작업자 임의 소스 배합 변경

## 21. 매장 체크리스트

매장에서는 다음 항목을 확인한다.

- 반반 다짐육 원팩 라벨 확인
- 제조일 및 사용기한 확인
- 매운불고기 소스 준비 확인
- 마늘쫑 품질 확인
- 마늘쫑 세척 및 절단 상태 확인
- 볶음육 바싹함 확인
- 국물 잔량 없음 확인
- 김밥 조립 시 속재료 쏠림 없음 확인
- 절단면 품질 확인
- 판매 전 맛과 온도 확인
- 폐기량 기록

## 22. 본사 관리 포인트

본사는 다음 데이터를 기준으로 메뉴를 관리한다.

- 매장별 판매량
- 시간대별 판매량
- 반반 다짐육 사용량
- 매운불고기 볶음육 제조량
- 마늘쫑 사용량
- 마늘쫑 폐기량
- 고객 클레임
- 매운맛 관련 피드백
- 마늘쫑 식감 관련 피드백
- 언양식 바싹불고기 김밥과의 판매 비율
- 원가율
- 조리 편차

## 23. 시즌 종료 기준

다음 조건 중 하나에 해당하면 시즌 종료를 검토한다.

- 마늘쫑 품질 저하
- 마늘쫑 단가 급등
- 판매량 급감
- 폐기량 증가
- 매장 조리 편차 증가
- 고객 반응 저하
- 본사 시즌 메뉴 교체 결정

시즌 종료 후 반반 다짐육 원팩은 언양식 바싹불고기 김밥 등 상시 메뉴로 전환 사용한다.

## 24. 향후 보정 과제

다음 항목은 테스트 후 확정한다.

- 정확한 매운불고기 소스 배합비
- 1줄당 매운불고기 볶음육 투입량
- 1줄당 마늘쫑 투입량
- 마늘쫑 절단 크기
- 마늘쫑 데침 여부
- 마늘쫑 투입 시점
- 볶음 시간
- 적정 수분 제거 기준
- 밥 양과 고기 양의 비율
- 깻잎 적용 여부
- 포장 후 식감 유지 시간
- 배달 메뉴 적용 가능성
