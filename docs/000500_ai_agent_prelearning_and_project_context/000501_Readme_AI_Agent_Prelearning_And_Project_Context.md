## Non-Authorization Boundary

This folder does not authorize implementation.

Reading this folder, generating plans, reviewing documents, summarizing scope, or preparing context does not grant permission to modify runtime code, SQL, Flutter/Dart, Supabase logic, migration files, configuration, lock files, generated files, or production behavior.

All implementation must go through the 51355 pipeline.

## AI Agent Roles

Cursor is responsible for search, impact scope discovery, file inventory, dependency tracing, and terminal raw log collection.

Claude is responsible for architecture, design reasoning, implementation planning, risk review, and audit.

Codex is a restricted implementer and may only act inside explicitly approved file paths and explicitly approved operations.

The human owner is responsible for final approval, merge decisions, release approval, and production responsibility.

## Implementation Gate

Implementation remains blocked unless the required pipeline artifacts exist and the human owner explicitly approves the scope.

The minimum expectation is that the agent can identify the approved WorkPackage, impact scope, context snapshot, overview, logic, test plan, change contract, allowed files, allowed operations, forbidden files, forbidden operations, validation plan, rollback plan, and human approval record.

## Final Rule

No AI edits without scope.
