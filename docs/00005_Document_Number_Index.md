# 00005 Document Number Index

## 1 Purpose

This document indexes governance files and the active `docs/` domain documentation spine inside `yoonsul_wait_order_handoff`.

Documentation paths use five-digit prefixes and approximately 2,000-slot domain bands. Root-level duplicate and residual staging files are listed separately and are not canonical domain documents.

Status values:

- `active`: current governance or design authority.
- `initial`: domain landing document.
- `moved`: document moved from temporary `docs/` root placement into a domain folder or renumbered during placement.
- `future-reference`: future-facing reference document, not active MVP runtime approval.
- `unresolved-duplicate`: root-level duplicate/residual staging file intentionally not moved to avoid overwrite, deletion, or accidental canonicalization.
- `conflict-review`: preserved conflict/review copy, not a canonical domain document.
