# 016000_Readme_Admin_Console_And_SaaS_Operations_Control

## Purpose

This folder is the documentation domain for admin console controls and SaaS operations administration for CatchMenu / Catch & Order.

## Scope

- Admin console operating model and governance boundary (no runtime implementation)
- SaaS tenant control policy, tenant lifecycle, and role/action mapping
- Store control admin policy and activation/suspension workflow
- Operator role/permission control and provider configuration control
- POS/KDS/payment provider setting management
- Feature flag rollout control and rollback
- Risk, financial reconciliation, audit log, and evidence packet admin views
- Approval workflow console, incident recovery console, webhook integration health console
- Security policy console, data retention/export console
- Customer center and implementation handoff admin views
- Release/rollback admin views

## File List

- `016179_Index_Admin_Console_And_SaaS_Operations_Control_Expansion_Wave_1.md` — full manifest of the 80-document Wave 1 batch (Batch 7G)
- `016100`-`016178` — governance, overview, boundary, checklist, matrix, report, template, runbook, and audit documents per the areas listed above

## Non-Scope

- Runtime implementation, SQL, Flutter/Dart, or Supabase changes
