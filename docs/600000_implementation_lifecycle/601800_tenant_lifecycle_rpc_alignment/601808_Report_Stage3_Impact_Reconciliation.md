**`601807` §7 마지막 행 — `000701` §47.1 3단계 actor 지정과 `601700` 실제 수행의 불일치.**

```text
소관은 governance 이며 이 나선 밖이다
```

**33건 집계에 포함하지 않았다.**

### §5.6 `601807` 자체의 관측 — 4건
