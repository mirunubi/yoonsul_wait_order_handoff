## §0 성격과 범위

`000701` §47.1 의 **4단계 설계문서 정합화** 산출물이다.

```text
601801 선언과 601803 모델을 불변조건으로 옮긴 것이며 구현 설계가 아니다
```

**`601713`(0-A Logic)과의 분업**

```text
601713   구조 불변조건 — 관계 · cardinality · 어휘
601810   상태 불변조건 — 전이 · 동시성 · 격리 범위 · 감사
```

> ⚠️ **물리 변경 방법을 쓰지 않는다.**
> **「어떻게 고칠지」는 ChangeContract(`601812`) 소관이다.**
>
> **`601713` §3 예외 `X-1`~`X-11` 이 「무엇이 참이어야 하는가」로만 기술됐고
> 복구 SQL 을 담지 않았다. 같은 원칙을 따른다.**

> ⚠️ **`601801` 에 없는 선언을 만들지 않는다.**
> **미선언 전이를 채우지 않는다**(`HG-A-10`).

**`601809` §4 판정을 전제로 삼는다.**

```text
isolate_tenant 를 같은 이름 · 같은 자리에서 수리한다
신규 함수를 만들고 기존을 폐기하는 재작성을 택하지 않는다
```

**검증 등급 — A**(`HD-0-A-2-1`).

### §0.1 식별자 규칙

```text
I-N   불변조건 — 무엇이 참이어야 하는가
X-N   예외 상황 — 현재 참이 아닌 것
Q-N   이 Logic 이 답하지 못한 것
```

**각 `I-N` 은 `HG-A-N` 또는 `HD-0-A-2-N` 을 근거로 갖는다.**
