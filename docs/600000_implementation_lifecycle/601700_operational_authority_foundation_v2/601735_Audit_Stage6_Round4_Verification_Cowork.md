`601730` CW-B1 은 D-14 「§4.1 정의 그대로」의 딜레마를 두 갈래로 제시했다.

```text
읽기 A   D-14 의 「그대로」에 인라인 UNIQUE·FK 가 포함된다   →  D-15 위반, TP-P-29 FAIL
읽기 B   D-14 에서 UNIQUE·FK 를 빼고 CREATE TABLE 한다      →  FK 를 만들 허용 동사가 사라진다
```

**13판은 읽기 B 를 채택했다.** `601717` L497:

> **D-14 는 5컬럼 테이블만 만든다.** UNIQUE 는 D-15, FK 는 §4.2 1a·D-19 가 만든다.

**UNIQUE 쪽은 닫혔다. FK 쪽은 열린 채다.**

N-6″·N-8″ 를 정합화해도 **호출 경로를 통한 검증은 여전히 불가능**하고, `authenticated` EXECUTE 를 통한 **직접 호출 검증만 가능**하다.
후속 RPC alignment 나선이 **「경로 검증」과 「직접 호출 검증」을 구분**하지 않으면 H-1 완료 판정이 흔들린다.
