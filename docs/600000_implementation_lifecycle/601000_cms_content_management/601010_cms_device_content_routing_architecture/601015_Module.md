## Summary

Implemented the approved `cms_device_registry_edid_mapping` change (`601014_ChangeContract_Cms_Device_Registry_Edid_Mapping.md`, Option 3 per `601012_Logic_Cms_Device_Registry_Edid_Mapping.md` §2): added 4 nullable EDID-related columns to `catchmenu_store.did_devices` and created 2 new Stage-A registry RPCs, without touching `update_did_display()` (`0043`) or `device_registry`.

## 2. Schema Change

| Column | Type | Nullable |
|---|---|---|
| `edid_serial` | `text` | Yes |
| `last_detected_edid` | `text` | Yes |
| `last_edid_check_at` | `timestamptz` | Yes |
| `physical_position_label` | `text` | Yes |

All 4 added via `add column if not exists` — no `NOT NULL`, no default, per `601014_ChangeContract.md` §2's explicit prohibition (existing `did_devices` rows have no EDID data and would otherwise break).

## 3. New Functions

- **`catchmenu_store.get_did_device_by_edid(p_tenant_id, p_store_id, p_edid_serial, p_locale default 'ko')`** — read-only lookup. Returns device fields (`device_id`, `registry_device_id`, `did_code`, `did_name`, `display_mode`, `zone`, `orientation`, `resolution`, `edid_serial`, `last_detected_edid`, `last_edid_check_at`, `physical_position_label`) for an active device matching the given EDID within tenant/store scope, ordered by `updated_at desc, created_at desc` (most-recently-touched match wins if duplicates exist). Returns `success: false, error_key: 'edid_not_registered'` if no match.
- **`catchmenu_store.report_did_device_edid_scan(p_tenant_id, p_store_id, p_device_id, p_detected_edid, p_correlation_id default null)`** — write path. Updates `last_detected_edid`/`last_edid_check_at` unconditionally (row-locked via `for update`), then computes `is_mismatch := edid_serial is distinct from p_detected_edid` and returns it in the response. Returns `success: false, error_key: 'did_device_not_found'` if the device_id doesn't resolve within tenant/store scope.
