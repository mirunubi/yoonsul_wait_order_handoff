## 1. 문서 목적

본 SOP는 윤슬김밥의 상시 시그니처 메뉴 후보인 언양식 바싹불고기 김밥의 원재료, 소스, 조리, 보관, 김밥 조립, 품질 기준, 매장 운영 기준을 정의한다.

본 메뉴는 반반 다짐육 원팩을 공통 원재료로 사용하되, 간장 베이스 짠단 소스를 적용하여 국물 없이 바싹 볶은 불고기 속재료를 만드는 것을 핵심으로 한다.

## 2. 메뉴 개념

언양식 바싹불고기 김밥은 소고기와 돼지 앞다리살을 섞은 반반 다짐육 원팩을 간장, 마늘, 단맛, 감칠맛 중심의 소스에 볶아 만든 김밥이다.

고객에게는 다음 이미지로 전달한다.

- 바싹 볶은 불고기 풍미
- 짠단 감칠맛
- 식어도 퍽퍽하지 않은 부드러운 고기 식감
- 김밥 안에서 흐르지 않는 안정적인 속재료
- 상시 판매 가능한 시그니처 고기 김밥

## 3. 원재료 기준

### 3.1 공통 원육

본 메뉴는 반반 다짐육 원팩을 사용한다.

기본 배합은 다음과 같다.

- 소고기 다짐육 50%
- 돼지 앞다리살 다짐육 50%

배합비는 별도 원팩 SOP를 따른다.

### 3.2 주요 부재료

언양식 바싹불고기 김밥에는 다음 부재료를 사용할 수 있다.

- 밥
- 김
- 단무지 또는 절임무
- 우엉 또는 대체 절임채소
- 계란지단
- 당근채
- 오이 또는 초록 채소
- 깻잎 또는 향채 선택 가능
- 참기름
- 깨

부재료는 브랜드 전체 김밥 표준과 충돌하지 않도록 조정한다.

## 4. 소스 기준

### 4.1 소스 방향

언양식 바싹불고기 소스는 간장 베이스의 짠단 감칠맛을 기준으로 한다.

소스의 목적은 다음과 같다.

- 고기 잡내 제거
- 간장 감칠맛 부여
- 단맛을 통한 대중성 확보
- 마늘과 파 향을 통한 불고기 풍미 강화
- 김밥 속재료로 사용할 수 있도록 수분을 과하게 남기지 않음

### 4.2 기본 소스 구성

초기 테스트용 소스 구성은 다음 방향으로 설계한다.

- 간장
- 다진 마늘
- 양파즙 또는 양파 다짐
- 배즙 또는 과일 단맛 대체재
- 설탕 또는 비정제당 소량
- 물엿 또는 조청 소량
- 후추
- 참기름
- 깨
- 대파 또는 파기름 선택 가능

정확한 배합비는 테스트 조리 후 별도 레시피 카드에서 확정한다.

## 5. 조리 전 준비

조리 전 다음 사항을 확인한다.

- 반반 다짐육 원팩 라벨 확인
- 제조일 및 사용기한 확인
- 냉장 또는 해동 상태 확인
- 이취, 변색, 점액 여부 확인
- 조리도구 세척 및 소독 확인
- 팬 또는 볶음솥 예열 상태 확인
- 소스 준비 여부 확인
- 완성 후 담을 트레이 준비

라벨이 없거나 사용기한이 불명확한 원팩은 사용하지 않는다.

## 6. 조리 절차

### 6.1 기본 볶음 절차

1. 팬 또는 볶음솥을 예열한다.
2. 필요 시 소량의 식용유를 두른다.
3. 반반 다짐육 원팩을 넣고 중강불에서 풀어가며 볶는다.
4. 고기가 뭉치지 않도록 주걱으로 고르게 풀어준다.
5. 고기 표면의 붉은 기가 사라질 때까지 1차 볶음한다.
6. 과도한 수분이나 기름이 많으면 일부 제거한다.
7. 간장 베이스 소스를 넣는다.
8. 소스가 고기에 흡착되도록 계속 볶는다.
9. 국물이 남지 않도록 바싹 볶는다.
10. 마지막에 참기름과 깨를 넣어 마무리한다.
11. 완성된 볶음육을 트레이에 펼쳐 빠르게 식힌다.

### 6.2 바싹 볶음 기준

본 메뉴의 핵심은 바싹 볶음이다.

다음 상태를 목표로 한다.

- 팬 바닥에 소스가 흥건하게 남지 않음
- 고기 표면에 소스가 코팅되어 있음
- 김밥에 넣었을 때 밥이 젖지 않음
- 고기가 마르거나 딱딱하지 않음
- 식어도 풍미가 유지됨

### 6.3 금지되는 조리 상태

다음 상태는 불량으로 본다.

- 국물이 많이 남은 상태
- 고기가 큰 덩어리로 뭉친 상태
- 탄맛이 강한 상태
- 간장 쓴맛이 올라온 상태
- 과도하게 단 상태
- 식었을 때 기름이 과하게 굳는 상태
- 김밥 조립 시 밥을 젖게 만드는 상태

## 7. 김밥 조립 기준

### 7.1 조립 전 준비

김밥 조립 전 다음 사항을 확인한다.

- 밥 온도
- 김 상태
- 불고기 볶음육 온도
- 부재료 준비 상태
- 김밥 말이 도구 위생
- 작업자 장갑 상태

불고기 볶음육은 너무 뜨거운 상태로 사용하지 않는다. 과열 상태의 속재료는 김과 밥의 식감을 떨어뜨릴 수 있다.

### 7.2 조립 원칙

언양식 바싹불고기 김밥은 고기 풍미가 중심이 되도록 조립한다.

조립 시 다음 기준을 따른다.

- 밥은 과도하게 두껍게 깔지 않는다.
- 불고기 볶음육은 중앙에 고르게 배치한다.
- 단무지와 절임채소는 짠맛 균형을 고려하여 사용한다.
- 계란지단은 고기 풍미를 부드럽게 받쳐주는 역할로 사용한다.
- 당근채와 초록 채소는 색감과 식감 보완용으로 사용한다.
- 김밥을 말 때 불고기 속재료가 한쪽으로 쏠리지 않도록 한다.

## 8. 1줄 기준 품질

완성된 김밥 1줄은 다음 기준을 만족해야 한다.

- 절단면에서 불고기 속재료가 명확히 보일 것
- 고기가 한쪽으로 몰리지 않을 것
- 밥과 속재료의 균형이 무너지지 않을 것
- 김이 눅눅하지 않을 것
- 절단 시 속재료가 과도하게 빠지지 않을 것
- 첫맛은 간장 불고기 풍미, 끝맛은 고소함으로 정리될 것

## 9. 판매 및 제공 기준

- 바싹 볶은 불고기 김밥

고객 설명은 과도하게 기술적으로 하지 않고, 맛 중심으로 전달한다.

- 짠맛이 강하면 간장 비율 또는 졸임 시간을 조정한다.
- 단맛이 강하면 당류를 줄인다.
- 고기 잡내가 있으면 마늘, 파, 후추, 양파 처리를 조정한다.

- 수분이 많으면 볶음 시간을 늘리거나 소스 투입량을 줄인다.
- 김밥 안에서 존재감이 약하면 불고기 투입량을 조정한다.
